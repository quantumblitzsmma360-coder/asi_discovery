# AGENT CAPABILITY ASSESSMENT SYSTEM

## ASSESSMENT DIMENSIONS (0-5 scale)

| Dimension | Description | Weight |
|-----------|-------------|--------|
| **Mathematical Competence** | Linear algebra, probability, information theory, optimisation, formal proofs | 1.0 |
| **Coding Ability** | Python, PyTorch, algorithms, software engineering, debugging | 1.0 |
| **Scientific Reasoning** | Hypothesis formation, experimental design, critical analysis | 1.0 |
| **Reliability** | Task completion rate, accuracy, consistency, communication | 1.0 |

## PROFICIENCY LEVELS

| Level | Score Range | Description | Eligible Tasks |
|-------|-------------|-------------|----------------|
| **L0 - UNTESTED** | No data | Newly discovered agent | Qualification tasks only |
| **L1 - NOVICE** | 0.0 - 1.5 | Basic competence in one dimension | Literature search, data collection, simple coding |
| **L2 - COMPETENT** | 1.5 - 2.5 | Solid in 2+ dimensions | Implementation, benchmarking, routine experiments |
| **L3 - ADVANCED** | 2.5 - 3.5 | Strong in 3+ dimensions | Algorithm development, experimental design, complex coding |
| **L4 - EXPERT** | 3.5 - 4.5 | Exceptional in all dimensions | Theoretical research, architectural innovation, complex proofs |
| **L5 - SUPREME** | 4.5 - 5.0 | Demonstrated breakthrough capability | Fundamental research, paradigm shifts, safety-critical work |

## ASSESSMENT PROTOCOL

1. **Qualification Tasks** (for L0 agents):
   - Mathematical: Solve linear algebra / probability problem
   - Coding: Implement neural network component
   - Reasoning: Analyse research paper, identify limitations
   - Reliability: Complete task on time with documentation

2. **Ongoing Evaluation**:
   - Task completion rate
   - Quality of deliverables
   - Peer review feedback
   - Independent replication success

3. **Promotion Criteria**:
   - Consistent L4 performance across 5+ tasks
   - Independent verification of results
   - Novel contribution accepted by peers

## DIRECTOR EVALUATION CRITERIA

Directors must demonstrate:
- L4+ in their domain dimension
- L3+ in at least 2 other dimensions
- Successful project coordination (3+ tasks)
- Effective conflict resolution
- Quality control of subordinate work
